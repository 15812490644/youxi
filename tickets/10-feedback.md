# 10 · 反馈面板：状态快照导出

Status: open
Blocked by: 08

## 目标

ADR-0006 称它是「人工反馈回路的吞吐瓶颈」。没有它，「手感太滑」这类意见无法定位，迭代会卡死在猜测上。这个模块是**正式功能，不是调试脚手架**。

## 涉及模块

`feedback.js`、`storage.js`（快照拼装）

## 验收（必须可观测）

1. 右下角常驻小按钮，点开为浮层（右下角区域职责不变，L0-D）
2. **一键复制运行时状态快照**（JSON），包含：
   - 当前分数、`baseHP`、伙伴队列（种类与顺序）
   - `shield` / `stun` / `recoil` 状态、三个技能 CD
   - **`config.js` 全量参数值**（把「太滑」翻译成 `MOVE_INTERVAL=150ms` 的关键）
   - FPS、设备与浏览器信息
   - **最近 20 条事件日志**（`EVENT_LOG_SIZE`）
3. 意见输入框：验收人写主观感受
4. 一键复制把「意见 + 快照」打包成一段文本
5. 事件日志覆盖：受伤 / 消耗 / 击杀 / 地形摧毁 / 区块生成回收 / BOSS 刷新

## 约束

- 日志埋点从 01 就要有，本 ticket 是把它**暴露出来**，不是从头补（事后补的日志覆盖不到早期 bug）
- 快照只读状态，不得修改游戏状态
- 禁止外部请求把快照上传——只复制到剪贴板（L0-9）

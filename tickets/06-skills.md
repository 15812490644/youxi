# 06 · 技能系统：dash / guard / slash

Status: open
Blocked by: 04

## 目标

三个技能开局全部可用、各自独立冷却。它们不只是战斗手段——`slash` 还是三种地形摧毁来源之一，是玩家主动改造地图的唯一途径。

## 涉及模块

`skills.js`（三个技能、冷却、无敌帧）、`state.js`（技能 CD）、`ui.js`（冷却环）、`models.js`（特效）

## 验收（必须可观测）

1. 开局三个技能全部可用，不需要解锁
2. `dash`（`1` 键）：沿当前方向位移 3 格，位移期间无敌，撞到的怪物 -1 血，CD 10s
3. `guard`（`2` 键）：2 秒无敌，周围 1 格怪物被 `knockback` 弹开 2 格，CD 12s
4. `slash`（`3` 键）：周围 3×3 所有怪物 -2 血，**同时砍平范围内所有危险地形**，CD 8s
5. 三个 CD **各自独立**，互不影响
6. 三个技能都不使冒险家受伤、都不触发 `recoil`——这是「技能 vs 硬撞」的对比基础（ADR-0009）
7. `dash` 可穿过地形格，但地形效果在**落点格**结算
8. HUD 图标显示冷却环：冷却中灰显 + 读秒，就绪时高亮脉冲
9. `1`/`2`/`3` 键与点击图标**双通道**都能释放
10. 技能不消耗伙伴、不占队伍位（L0-E）
11. `eventLog` 记录 `skill_cast` / `knockback` / `terrain_destroy`

## 约束

- 技能必须主动释放、必须有独立冷却、不消耗伙伴、不占队伍位（L0-E）
- **不得新增按键**（L0-B）：只能占 `1`/`2`/`3` 或 HUD 点击
- 不得改变 04 建立的结算顺序（L0-C）
- 冷却值、距离、伤害、范围全部读 `config.js`

# 08 · 界面与 HUD：四界面 + 三区 HUD

Status: open
Blocked by: 04

## 目标

把已有的状态呈现在屏幕上，并跑通 `start → playing → over → leaderboard` 的状态机闭环。

## 涉及模块

`ui.js`（HUD、界面切换、伙伴栏、技能图标、分数动画）、`state.js`（状态机）、`css/ui.css`、`css/sprites.css`

## 验收（必须可观测）

1. **开始界面**：标题、开始按钮、规则说明入口、排行榜入口
2. **游戏主界面**四区布局（位置与职责不得变动，L0-D）：
   - 左上：基础 HP（心形 ×3）+ 分数（加分时数字弹跳）
   - 右上：三个技能图标 + 冷却环
   - 底部：伙伴栏，按队伍顺序排列，同种折叠为「图标 ×N」
   - 右下：反馈按钮（10 做）
3. **结束界面**：最终分数、与历史最高分对比、存活时长、最长队伍、重开按钮、排行榜入口
4. **排行榜界面**：Top 10（分数 / 日期 / 存活时长 / 最长队伍）
5. 状态机闭环：`start → playing → over → (start | playing)`，`leaderboard` 可从 `start` 与 `over` 进入
6. **`baseHP` 与伙伴数显示为两个独立数值**，绝不共用同一个数字（ADR-0003）
7. 图标用 CSS 像素画或内联 SVG，**禁止外链图片与外链字体**（L0-9 运行时零外部请求）

## 约束

- **不得改变 UI 布局结构**（L0-D）：四个区的位置与职责已定死
- 禁止引入任何外部资源（CDN、图片、字体、图标库）
- 界面文案用中文，术语与 `GLOSSARY.md` 一致（基础 HP / 伙伴 / 护盾，不写「血量」「宠物」「无敌」）

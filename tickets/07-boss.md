# 07 · BOSS：3 种 + 波次轮换 + 技能调度

Status: open
Blocked by: 05, 06

## 目标

每 5 分钟来一只 BOSS，三种轮换。三种技能分别针对「走位 / 空间 / 反应」三种能力——这是长局节奏的来源。

## 涉及模块

`monsters.js`（BOSS 技能调度器）、`state.js`（波次计数跨刷新保持）、`models.js`（3 种造型）、`render3d.js`（技能特效）

## 验收（必须可观测）

1. 每 5 分钟刷新 1 只，顺序 `lavaTitan` → `frostKing` → `shadowLord` **循环**
2. 通用：血量 `5 + 2×波次`，碰撞 -3 `baseHP`，击杀 +500 分 + 3 个伙伴
3. `lavaTitan` 熔岩兽：直线突进 + 路径留火痕（3 秒，踩上 -1），**突进路径上的危险地形被摧毁**
4. `frostKing` 寒霜王：3 格减速光环（-50%）+ 周期召唤 `slime`，不摧毁地形
5. `shadowLord` 暗影领主：短距瞬移接近 + 周期范围震波（半径 3，-1），**震波范围内的危险地形被摧毁**
6. **每种 BOSS 的技能都必须存在躲避方式**（冲刺 / 护体 / 走位）——无解伤害属于禁止项（L0-E）
7. 波次计数跨刷新保持（存在 `state.js`）
8. `eventLog` 记录 `boss_spawn` / `boss_skill` / `terrain_destroy` / `boss_killed`
9. 无头测试覆盖：三种 BOSS 按序轮换，且各自技能可被固定种子复现

## 约束

- BOSS 满足普通怪全部约束，且至少一个技能、技能可躲、按波次刷新不常驻（L0-E）
- 血量与奖励三种统一，避免玩家为了奖励而偏好某一种（ADR-0011）
- 不得单用 `boss` 或 `boss1`/`boss2`/`boss3` 指代某一种——命名禁区

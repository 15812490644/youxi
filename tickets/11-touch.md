# 11 · 触屏通道（未真机验证）

Status: open
Blocked by: 01

## 目标

原始需求写了「适配手机屏幕且支持触屏滑动操作」。ADR-0005 的裁决是：**实现，但诚实标注未真机验证**——需求不应被静默丢弃，但假装已完成更糟。

## 涉及模块

`input.js`（触屏分支）、`css/ui.css`（移动端适配）

## 验收（必须可观测）

1. `touchstart` 记录起点、`touchend` 计算方向
2. 超过 24px 判定 swipe（`SWIPE_THRESHOLD`）
3. 同样**禁止 180° 直接反向**
4. 代码里明确标注「未真机验证」
5. **不得影响键盘手感**——键盘仍是主要验证通道
6. 桌面 DevTools 的 touch emulation 下能覆盖基本逻辑（无法模拟真实延迟与手势误触）

## 约束

- **在验收人明确放弃触屏之前，不得删除 `input.js` 中的触屏分支**（ADR-0005 明令）
- 不得为了适配触屏改动已有的按键与 UI 布局（L0-B / L0-D）
- 不得引入任何外部库来做手势识别

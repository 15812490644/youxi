# 术语表（GLOSSARY）

> 《冒险家与伙伴》通用语言
> **纪律**：代码中出现下列概念时，标识符必须与「代码标识」列完全一致。命名漂移会导致后续跨文件检索失效，视为违规（见 `RULES.md` L0-4）。
> **规格状态**：与 `PROMPT.md` 同步，已全部敲定

---

## 一、核心概念

| 术语 | 代码标识 | 定义 | 易混淆点 |
|---|---|---|---|
| 冒险家 | `adventurer` | 玩家直接控制的单位，即蛇头 | 不是"玩家"、不是"蛇" |
| 伙伴 | `companion` | 队伍节点，6 种动物，各有一次性被动能力 | 不是"道具"、不是"buff"、不是"技能" |
| 队伍 | `party` | 伙伴的有序序列，**尾部为最后加入者** | 消耗从尾部开始 |
| 消耗 | `consume` | 触发伙伴能力并将该伙伴移出队伍 | 消耗 ≠ 扣血 |
| 地形 | `terrain` | 地图格子的类型，4 种 | 与"地图"区分 |
| 地形摧毁 | `terrainDestroy` | 把某格危险地形变为 `grass` 的动作 | 三种来源：伙伴触发 / `slash` / BOSS 技能 |
| 怪物 | `monster` | 敌对单位统称，含普通怪与 BOSS | 与"地形"区分：怪物会动、有血量 |
| 威胁 | `threat` | 地形或怪物造成的伤害来源统称 | 抽象层，不对应具体实体 |
| 基础 HP | `baseHP` | 独立于伙伴数的生命值，归 0 即结束 | **不得**写作 `hp` / `health` / `life` |
| 护甲层 | `armorLayer` | 等于当前伙伴数量，抵挡威胁的第一层 | 不是数值上限，是实时长度 |
| 护盾 | `shield` | 熊猫给予的**临时一格血**（`SHIELD_POINTS: 1`），持续 1 分钟。**不是无敌**：受伤时先扣这一格，溢出伤害继续打 `baseHP` | 与"护甲层"完全不同机制；重复获得**不叠加**（永远一格），只重置计时 |
| 冲刺 | `dash` | 技能：3 格位移 + 无敌，CD 10s | 三个技能之一 |
| 护体 | `guard` | 技能：2 秒无敌 + 弹开周围怪物，CD 12s | 与 `shield` 不同：护体是玩家主动技能 |
| 斩击 | `slash` | 技能：周围 3×3 怪物 -2 血 + 砍平危险地形，CD 8s | 唯一的范围伤害兼地形摧毁手段 |
| 弹开 | `knockback` | 被 `guard` 击退的位移效果，2 格 | 不是伤害 |
| 眩晕 | `stun` | 失控状态，无法操作。**两种来源时长不同**：撞自身 3 秒 / 踩危险地形 1 秒 | 不是"减速"；不得与 `recoil` 混用 |
| 撞击硬直 | `recoil` | **撞怪物**后双方 0.5 秒僵直，期间不再触发碰撞伤害 | **不得**与 `stun` 混用 |
| 区块 | `chunk` | 无限地图的生成 / 回收单元 | 不是"关卡"、不是"屏幕" |
| 结算 | `resolve` | 按优先级处理一次碰撞 | 顺序不可调换 |
| 效果类型 | `effectType` | 实体触发时执行的行为分支名，取自第九节枚举表 | 新增类型要登记进第九节 |
| 启用开关 | `enabled` | 每个实体在 `config.js` 中的独立开关，置 `false` 即完全移除该实体 | AI 自主新增的必备项 |
| 本地库目录 | `vendor` | 存放第三方库（three.js）的目录，运行时零外部请求 | 不是"依赖包"、不参与构建 |

**`stun` 与 `recoil` 对照**（最容易写错的一对）：

| | `stun` 眩晕 | `recoil` 撞击硬直 |
|---|---|---|
| 触发 | 撞到自己的队伍（3s）/ 踩危险地形（1s） | 普通移动撞到怪物 |
| 时长 | 3000ms / 1000ms | 500ms |
| 影响对象 | 只影响冒险家 | 冒险家与怪物双方 |
| 表现 | 画面灰化 + 抖动，无法操作 | 短暂僵直，不能再次触发碰撞伤害 |

## 二、伙伴（6 种，全部被动）

> **本质约束**：伙伴一律被动触发，玩家永远不能主动释放。想做"点击释放"的东西，请做成技能。

| 中文 | 代码标识 | 触发条件 | 效果 | 稀有度 | 收集分 |
|---|---|---|---|---|---|
| 小龙 | `dragon` | 进入 `volcano` 地形 | 安全通过 + **摧毁该格火山** | 稀有 | 20 |
| 凤凰 | `phoenix` | 进入 `glacier` 地形 | 安全通过 + **摧毁该格冰川**（连减速一起消除） | 稀有 | 20 |
| 小狐狸 | `fox` | 进入 `thorn` 地形 | 安全通过 + **摧毁该格荆棘** | 普通 | 10 |
| 熊猫 | `panda` | 碰撞 `ironGolem` | 击杀铁怪 + 获得 `shield`（临时一格血，1 分钟） | 稀有 | 20 |
| 乌龟 | `turtle` | 受到 `archer` 远程攻击 | 抵挡该次攻击 + 反杀该弓箭手 | 普通 | 10 |
| 小狼 | `wolf` | **被动**：击杀任意怪物且 `baseHP` 未满 | 消耗 1 只 `wolf`，`baseHP` +1 | 普通 | 10 |

**消耗规则**：从队伍**尾部**开始消耗。玩家刚收集的伙伴会最先被用掉——收集顺序即策略。

**三个定位**：

- **摧毁地形型**（`dragon` `phoenix` `fox`）：用一只伙伴换一格永久安全
- **战斗型**（`panda` `turtle`）：对付特定怪物
- **续航型**（`wolf`）：唯一能回血的伙伴

## 三、地形（4 种）

> **本质约束**：地形静态或周期性变化、可被摧毁、踩上去才生效、必须写明克星、**不得聚堆形成屏障**。

| 中文 | 代码标识 | 有对应伙伴时 | 无对应伙伴时 | 克星伙伴 | 生成权重 |
|---|---|---|---|---|---|
| 普通草地 | `grass` | — | 无害 | — | 76 |
| 火山 | `volcano` | 消耗 `dragon`，该格变 `grass` | 扣 1 `baseHP` + `stun` 1 秒 | `dragon` | 8 |
| 冰川 | `glacier` | 消耗 `phoenix`，该格变 `grass` | 减速 50% 持续 2 秒 + `stun` 1 秒 | `phoenix` | 8 |
| 荆棘 | `thorn` | 消耗 `fox`，该格变 `grass` | 扣 1 `baseHP` + `stun` 1 秒 | `fox` | 8 |

**生成四原则**：不聚堆（3×3 邻域内同类 ≤ 2 格）/ 不形成屏障 / 动态生成无边界 / 出生点 5×5 强制安全。

**摧毁来源**：伙伴触发 / `slash` 斩击（周围 3×3）/ BOSS 技能（`lavaTitan` 突进路径、`shadowLord` 震波范围）。摧毁后变 `grass`，`chunk` 回收重建时按权重重新掷骰。

## 四、怪物（3 种普通怪 + 3 种 BOSS）

### 普通怪

| 中文 | 代码标识 | 血量 | 行为 | 碰撞伤害 | 克星 | 击杀分 |
|---|---|---|---|---|---|---|
| 史莱姆 | `slime` | 1 | 随机游走 | -1 `baseHP` | 无 | 20 |
| 弓箭手 | `archer` | 2 | 保持距离，周期远程射击 | -1 `baseHP` | `turtle` | 50 |
| 铁怪 | `ironGolem` | 3 | 极慢巡逻，**不追逐** | -2 `baseHP` | 仅 `panda` 可秒杀 | 100 |

### BOSS（3 种，按波次轮流刷新）

| 中文 | 代码标识 | 血量 | 技能 | 摧毁地形 |
|---|---|---|---|---|
| 熔岩兽 | `lavaTitan` | 5 + 2×波次 | 直线突进；路径留火痕（3 秒，踩上 -1） | 是（突进路径） |
| 寒霜王 | `frostKing` | 5 + 2×波次 | 3 格减速光环（-50%）；周期召唤 `slime` | 否 |
| 暗影领主 | `shadowLord` | 5 + 2×波次 | 短距瞬移接近；周期范围震波（半径 3，-1） | 是（震波范围） |

三种 BOSS 通用：碰撞伤害 -3 `baseHP`，击杀 +500 分 + 3 个伙伴。刷新顺序 `lavaTitan` → `frostKing` → `shadowLord` 循环。

**玩家对怪物造成伤害的手段**：

| 手段 | 对怪物伤害 | 冒险家是否受伤 | 是否触发 `recoil` |
|---|---|---|---|
| 普通移动撞击（互伤） | 1 | 是，按该怪物伤害值结算 | 是，0.5 秒 |
| `dash` 冲刺撞击 | 1 | 否（无敌） | 否 |
| `slash` 斩击 | 2（范围 3×3） | 否 | 否 |
| `guard` 护体 | 0（仅 `knockback`） | 否（无敌） | 否 |

## 五、技能（3 个，全部主动）

> **本质约束**：技能必须玩家主动释放、必须有独立冷却、不消耗伙伴、不占队伍位。

| 中文 | 代码标识 | 按键 | 效果 | 冷却 |
|---|---|---|---|---|
| 冲刺 | `dash` | `1` | 沿当前方向位移 3 格，期间无敌，撞到的怪物 -1 血 | 10s |
| 护体 | `guard` | `2` | 2 秒无敌，周围 1 格怪物 `knockback` 2 格 | 12s |
| 斩击 | `slash` | `3` | 周围 3×3 所有怪物 -2 血 + 砍平范围内危险地形 | 8s |

三个技能开局全部可用，**各自独立冷却**，互不影响。

## 六、受击结算优先级（不可调换）

```
1. shield 生效中      → 护盾先吸收 1 点，护盾消失；**剩余伤害进入下一步**
2. 存在对应 companion → consume 该伙伴（从队伍尾部），剩余伤害**全部免除**
                        （若来源是地形，额外摧毁该格地形）
3. 否则               → baseHP -= **剩余伤害**
                        （若来源是危险地形，额外触发 stun 1 秒）
4. baseHP <= 0        → 游戏结束
```

> 护盾只吸收 1 点，**不是无敌**。被 BOSS 撞（3 点伤害）且无对应伙伴时：护盾吃掉 1 点，剩 2 点打在 `baseHP` 上。

**地形单独走这条**：

```
进入危险地形格：
  ├─ 有对应伙伴 → consume 伙伴 + 该格变 grass，无任何惩罚
  └─ 无对应伙伴 → baseHP -1（或减速）+ stun 1 秒 + 屏幕抖动
```

**互伤步骤**（仅在普通移动撞怪物时附加）：

```
a. 冒险家按上面的优先级结算受伤
b. 同时该怪物 -1 血
c. 双方进入 recoil 0.5 秒，期间不再触发碰撞伤害
```

`dash` / `slash` / `guard` 造成的伤害不走 a 与 c。

## 七、命名禁区

| 禁止 | 应使用 |
|---|---|
| `health` / `hp` / `life` / `blood` | `baseHP` |
| `snake` / `player` / `hero` | `adventurer` |
| `body` / `tail` / `segment` | `party` / `companion` |
| `item` / `powerup` / `buff` | `companion` |
| `enemy` / `mob` | `monster` |
| `map` / `level` / `screen` | `grid` / `chunk` |
| `hit` / `damage()`（泛指） | `resolve()`（结算） |
| **`stun` 用于描述撞怪物的僵直** | `recoil` |
| **`recoil` 用于描述撞自身/踩地形的失控** | `stun` |
| **单用 `boss` 指代某一种 BOSS** | `lavaTitan` / `frostKing` / `shadowLord` |
| `boss1` / `boss2` / `boss3` | `lavaTitan` / `frostKing` / `shadowLord` |
| `invincible` / `invincibility`（泛指） | `shield`（熊猫给的）或 `dash` / `guard` 的无敌帧，需写明是哪个 |
| **把伙伴写成可主动释放** | 伙伴一律被动；主动的东西做成 `skill` |
| **把技能写成自动触发** | 技能一律主动；被动的东西做成 `companion` |
| `destroy` / `remove` / `clear`（泛指地形） | `terrainDestroy` |

## 八、模块与文件命名

全局命名空间为 `window.ADV`。每个模块在 `ADV` 下挂一个对象，名称与文件名去掉 `.js` 后一致：

```
ADV.config  ADV.state  ADV.grid  ADV.terrain  ADV.companions
ADV.monsters  ADV.skills  ADV.collision  ADV.models  ADV.render3d
ADV.input  ADV.ui  ADV.storage  ADV.feedback  ADV.main
```

禁止往 `window` 上直接挂任何其它变量。
